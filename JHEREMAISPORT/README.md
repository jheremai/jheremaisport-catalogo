# SPORTZONE - Catálogo digital

Proyecto educativo de catálogo digital desarrollado con HTML, CSS y JavaScript.

## Cómo abrirlo
1. Descomprime la carpeta `SPORTZONE`.
2. Abre Visual Studio Code.
3. Selecciona **Archivo > Abrir carpeta** y elige `SPORTZONE`.
4. Abre `index.html` en el navegador. También puedes instalar la extensión **Live Server** en VS Code y seleccionar **Open with Live Server**.

## Estructura
- `index.html`: contenido y estructura de la página.
- `css/estilos.css`: colores, distribución y diseño adaptable.
- `js/script.js`: productos, búsqueda, filtros y carrito demostrativo.
- `img/`: iconos del proyecto.

## Publicar en Netlify
1. Entra a https://app.netlify.com/ y crea una cuenta o inicia sesión.
2. En el panel de Netlify, busca la opción para añadir un sitio y desplegar manualmente (Deploy manually).
3. Arrastra la carpeta `SPORTZONE` descomprimida al área de despliegue.
4. Espera a que termine y abre el enlace `.netlify.app` generado.

## Subir a GitHub
1. Entra a https://github.com/ e inicia sesión.
2. Crea un repositorio llamado `sportzone-catalogo`.
3. Sube los archivos y carpetas de `SPORTZONE` (no es necesario subir el ZIP).
4. Copia el enlace del repositorio para compartirlo.

## Antes de entregar
- Reemplaza el teléfono, correo y redes sociales de ejemplo por datos autorizados o deja claro que son demostrativos.
- Revisa los nombres, precios y fotografías.
- Comprueba la página en celular y computadora.
- Entrega los enlaces del repositorio GitHub y del sitio publicado en Netlify.

## Nota
Las fotografías se cargan desde Unsplash, por lo que se necesita conexión a Internet para verlas. El carrito es una simulación educativa: no procesa pedidos ni pagos reales.
